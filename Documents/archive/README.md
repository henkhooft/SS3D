# Archive

Shipped architecture efforts and completed plans. Kept as a historical record of **why** something was built a certain way. They are not maintained: links to code may be stale. For where code lives today, use the system maps (`Documents/architecture/systems/`).

The root `.ignore` hides this folder from default ripgrep and Grep searches. To search it on purpose, run `rg --no-ignore-dot <pattern> Documents/archive`.

When a doc moves here, and which docs stay active instead, is defined in [Documents/SKILL.md](../SKILL.md) (Archive).
